# Objetivo 3: Reconocimiento Cotidiano - Subdominios en uso

## Introducción

Actualmente muchas aplicaciones y servicios web utilizan **subdominios**
para separar diferentes funcionalidades dentro de un mismo dominio.

Un subdominio es una parte que se agrega antes del dominio principal y
permite organizar diferentes servicios, aplicaciones o secciones de una
plataforma.

Por ejemplo:

``` text
https://mail.google.com
```

En este caso:

-   Dominio principal: `google.com`
-   Subdominio: `mail`
-   URL completa: `https://mail.google.com`

Para esta actividad se identificaron diferentes aplicaciones y servicios
utilizados habitualmente que funcionan mediante subdominios.

------------------------------------------------------------------------

## 1. Software Seguro

**Aplicación:** Software Seguro - Plataforma de cursos

**URL completa:**

``` text
https://courses.softwareseguro.com.ar/
```

Partes de la dirección:

-   Dominio principal: `softwareseguro.com.ar`
-   **Subdominio: `courses`**

Representación:

``` text
https://[courses].softwareseguro.com.ar/
          ↑
      Subdominio
```

En este caso, `softwareseguro.com.ar` corresponde al dominio principal
de Software Seguro, mientras que `courses` es el subdominio utilizado
para acceder a su plataforma de cursos.

Este servicio se utiliza para acceder al contenido y a las actividades
del curso de Software Seguro.

## Conclusión

Mediante esta actividad se pudo observar que el uso de **subdominios es
muy común en aplicaciones web utilizadas diariamente**.

Los subdominios permiten a una organización separar distintos servicios
o funcionalidades manteniéndolos asociados a un mismo dominio principal.

Por ejemplo:

``` text
courses.softwareseguro.com.ar
```

utiliza `courses` como subdominio de `softwareseguro.com.ar`, mientras
que:

``` text
mail.google.com
drive.google.com
```

utilizan `mail` y `drive` como subdominios de `google.com`.

Reconocer esta estructura es importante en seguridad informática, ya que
permite comprender mejor cómo se organizan los servicios web y cómo una
misma organización puede disponer de diferentes aplicaciones o servicios
bajo distintos subdominios.
